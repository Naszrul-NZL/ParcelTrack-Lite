# M2 foundation

Shared request/response schemas and constants are in src/shared. Server tracking-token generation, canonical fingerprints and SQL transactions live in src/server. Parcel UI, creation/read APIs and public tracking are Phase 2/3 work, not implemented by the foundation.

Follow the [M2 plan](../../../docs/modules/module-2-parcels/README.md), [stock shadcn policy](../../../docs/ui-components.md) and [current design](../../../docs/design/current-design.md). The public preview currently lives in `src/features/preview`; replace its sample behavior with the real shared contract when implementing this module.
